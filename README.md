# AI Career Path Finder

AI Career Path Finder is a Python-based AI system designed to help freshers identify suitable career roles based on their skills, education, experience, and interests.

## Project Overview

The system analyzes a user's profile and compares their skills with the skills required for different career roles.

It provides:

- Suitable career roles
- Skill match percentage
- Skills already possessed
- Missing skills
- Skills that need improvement

The project will later be extended to generate personalized career roadmaps and interview preparation.

## Current Features

- User profile input
- Skill input
- Career role database
- Skill-based role matching
- Match percentage calculation
- Matched skill identification
- Missing skill identification
